# Dados

Os dados **não vão para o GitHub** (arquivos grandes). Baixe e coloque aqui:

1. Baixe o *Online Retail II* em https://archive.ics.uci.edu/dataset/502/online+retail+ii
2. Salve como `data/raw/online_retail_II.xlsx` (o arquivo tem duas abas: 2009-2010 e 2010-2011).
3. Rode `python scripts/preparar_dados.py` — gera `data/processed/vendas_limpas.csv.gz`.
